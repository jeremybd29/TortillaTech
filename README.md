TORTILLATECH

//Overview
TortillaTech is a console-based Point of Sale (POS) 
Customers can create a taco and burrito orders, customize ingredients, add drinks and chips & salsa,
Calculate totals, and save receipts to text files.

//Features 

//Create orders
- Add tacos
- Add burritos
- Add Drinks
- Add chips & salsa

//Customize tacos
- Select meat
- Select shell/tortilla type
- Add queso
- Add extra meat
- Add topping

//checkout
-display full order summary
-calculate total price
-Save receipt to file

//receipt generation
- Stored in receipts folder
- Contains order details and total cost

  // Encapsulation
